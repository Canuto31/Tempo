# Tempo — Casos de Uso

**Versión:** 1.1  
**Estado:** Roadmap inicial

> **Regla:** no avanzar a nuevos sprints ni agregar nuevos casos de uso hasta completar los sprints definidos en esta versión.

## Sprint 1 — Fundamentos

### CU-01 — Autenticación y perfiles
> Como usuario quiero registrarme e iniciar sesión mediante correo y contraseña o mediante Google para disponer de un perfil propio y acceder de forma segura a mis tareas, configuraciones, tiempos y estadísticas.

### CU-02 — Gestión de tareas
> Como usuario quiero crear, consultar, actualizar y eliminar mis tareas para gestionar las actividades que debo realizar.

### CU-03 — Información de una tarea
> Como usuario quiero definir para cada tarea un título, descripción, categoría, labels, deadline, tiempo propuesto y poker points para representar adecuadamente lo que debo realizar.

### CU-04 — Estados de las tareas
> Como usuario quiero asignar estados a mis tareas, como Backlog, En progreso, Completada o Bloqueada, para conocer su situación actual.

### CU-05 — Categorías y labels
> Como usuario quiero clasificar mis tareas mediante categorías y labels para organizarlas, filtrarlas y posteriormente obtener estadísticas sobre ellas.

## Sprint 2 — Jerarquía y progreso

### CU-06 — Tareas jerárquicas
> Como usuario quiero crear subtareas dentro de una tarea para dividir objetivos grandes en actividades más pequeñas.

### CU-07 — Jerarquía multinivel
> Como usuario quiero que una subtarea pueda contener a su vez otras subtareas para representar proyectos y actividades con diferentes niveles de profundidad.

### CU-08 — Progreso mediante subtareas
> Como usuario quiero visualizar el progreso de una tarea según el estado de sus subtareas para conocer cuánto del objetivo ha sido completado.

### CU-09 — Completado automático
> Como usuario quiero que una tarea padre se marque automáticamente como completada cuando todas sus subtareas hayan sido completadas.

## Sprint 3 — Planificación

### CU-10 — Planificación temporal
> Como usuario quiero establecer el periodo en el que planeo trabajar una tarea y definir cuánto tiempo quiero dedicarle para organizar mi trabajo.

### CU-11 — Planificación semanal
> Como usuario quiero establecer objetivos de trabajo para mis tareas durante una semana para comprometer una cantidad determinada de tiempo a cada actividad.

### CU-12 — Posponer tareas
> Como usuario quiero posponer una tarea para trasladar su planificación a un periodo posterior sin perder su historial.

### CU-13 — Repetición de tareas
> Como usuario quiero configurar tareas recurrentes por días, semanas o meses para evitar tener que crearlas manualmente cada vez.

### CU-14 — Periodos de planificación visuales
> Como usuario quiero identificar mediante colores el periodo en el que una tarea fue planificada para reconocer rápidamente tareas que pertenecen a semanas anteriores.

## Sprint 4 — Tiempo y Pomodoro

### CU-15 — Pomodoro general
> Como usuario quiero iniciar sesiones Pomodoro independientes de las tareas para utilizar la metodología Pomodoro durante mis actividades generales.

### CU-16 — Pomodoro asociado a una tarea
> Como usuario quiero iniciar una sesión Pomodoro asociada a una tarea para registrar el tiempo que dedico específicamente a ella.

### CU-17 — Registro de sesiones de trabajo
> Como usuario quiero registrar el tiempo dedicado a una tarea mediante sesiones de Pomodoro, cronómetro o registro manual para conocer el tiempo real invertido.

### CU-18 — Tiempo restante
> Como usuario quiero consultar cuánto tiempo me falta para alcanzar el tiempo objetivo de una tarea teniendo en cuenta el tiempo que ya he trabajado.

## Sprint 5 — Calendario y visualización

### CU-19 — Vista de calendario
> Como usuario quiero visualizar mis tareas en un calendario para conocer cómo está distribuido mi trabajo durante los días, semanas y meses.

### CU-20 — Vista Kanban
> Como usuario quiero visualizar mis tareas mediante un tablero Kanban para gestionarlas según su estado.

### CU-21 — Cambio de vista
> Como usuario quiero cambiar entre diferentes vistas, como lista, calendario y Kanban, para visualizar y gestionar mis tareas según mis necesidades.

## Sprint 6 — Cumplimiento y estadísticas

### CU-22 — Evaluación del cumplimiento semanal
> Como usuario quiero conocer si cumplí los objetivos de trabajo establecidos para cada semana para medir qué tan fiel fui a mi planificación.

### CU-23 — Identificación de incumplimientos
> Como usuario quiero que Tempo identifique las tareas que no fueron completadas ni pospuestas dentro del periodo planificado para diferenciarlas de las tareas que sí fueron gestionadas correctamente.

### CU-24 — Estadísticas de productividad
> Como usuario quiero consultar estadísticas sobre mis tareas, tiempo trabajado, tareas completadas, pospuestas e incumplidas para analizar mi productividad.

### CU-25 — Estadísticas de procrastinación
> Como usuario quiero identificar mediante estadísticas e indicadores visuales las tareas que he mantenido pendientes o replanificado repetidamente para conocer mis patrones de procrastinación.

### CU-26 — Historial de tareas
> Como usuario quiero consultar el historial de una tarea para conocer sus cambios de estado, planificación, posposiciones y tiempo trabajado.

## Sprint 7 — Inteligencia Artificial

### CU-27 — Generación de tareas mediante AI
> Como usuario quiero proporcionar un objetivo o proyecto a Tempo para que la AI proponga las tareas necesarias para completarlo.

### CU-28 — Descomposición inteligente
> Como usuario quiero que la AI descomponga una tarea compleja en subtareas para facilitar su ejecución y planificación.

### CU-29 — Mejora de planificación mediante AI
> Como usuario quiero recibir propuestas de planificación basadas en mis tareas, tiempo disponible y objetivos para organizar mejor mi trabajo.

### CU-30 — Replanificación inteligente
> Como usuario quiero recibir propuestas para reorganizar tareas incumplidas o atrasadas cuando mi planificación original ya no sea viable.

## Sprint 8 — Colaboración

### CU-31 — Compartir tareas
> Como usuario quiero compartir una tarea con otros usuarios para trabajar colaborativamente.

### CU-32 — Proyectos colaborativos
> Como usuario quiero crear proyectos compartidos para organizar tareas que deben ser realizadas por varias personas.

### CU-33 — Asignación de tareas
> Como usuario quiero asignar tareas a diferentes usuarios dentro de un proyecto para distribuir el trabajo.

### CU-34 — Permisos
> Como usuario quiero definir permisos sobre proyectos y tareas compartidas para controlar quién puede consultar o modificar la información.
